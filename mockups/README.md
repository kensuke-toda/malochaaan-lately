# UIモックアップ（G1）

Next.js実装前に見た目を確定させるための、単体HTML（Tailwind CDN使用）。ビルド不要、ブラウザで直接開けます。

## 見方

各ファイルをダブルクリックしてブラウザで開く、または以下のいずれかで確認してください。

```bash
npx serve mockups
```

`top.html` 右上の「ログイン状態を切替（モック用）」ボタンで、ログイン中／未ログイン時の見た目の違い（＋追加ボタンの表示/非表示）を確認できます。カレンダーの日付をクリックすると、その日の投稿内訳がカレンダー下に表示されます。

## デザイントーン（方針変更2）

温かみのあるミッドセンチュリー・モダンを基調（`top.html`等の`tailwind.config`にカラー定義あり）。

| トークン | 色 | 用途 |
|---|---|---|
| `cream` | `#F7EFE1` | ページ背景 |
| `paper` | `#FBF6EC` | カード・モーダル背景 |
| `sand` | `#EFE1C4` | 写真プレースホルダー・強調枠 |
| `walnut` | `#4A3527` | 本文テキスト（濃い茶） |
| `clay` | `#C1502E` | プライマリボタン・Ken・Placesドット |
| `mustard` | `#D9A441` | Thingsドット・アクセント |
| `teal` | `#4F7C73` | パートナー・Diaryドット |

フォントは見出しに `Fraunces`（セリフ、Google Fonts）、本文に `Nunito Sans` を使用。

## 確定後の移植方針

見た目がこれでOKになったら、`class` → `className` に置き換えつつ、対応する `src/app/**/page.tsx` にレイアウトを移植する（G8-5, G10-2）。データはSupabaseから取得する形に置き換え、カレンダー・追加モーダルはクライアントコンポーネント化する。
