# UIモックアップ（G1）

Next.js実装前に見た目を確定させるための、単体HTML（Tailwind CDN使用）。ビルド不要、ブラウザで直接開けます。

## 見方

各ファイルをダブルクリックしてブラウザで開く、または以下のいずれかで確認してください。

```bash
npx serve mockups
```

## ファイル一覧

| ファイル | 対応するWBS | 内容 |
|---|---|---|
| `top.html` | G1-1 | トップページ（Thingsギャラリー＋Diary一覧、投稿者バッジ付き） |
| `thing-detail.html` | G1-2 | モノの詳細ページ |
| `diary-detail.html` | G1-3 | 日記の詳細ページ |
| `login.html` | G1-4 | ログイン画面（サインアップなし、G7-1決定を反映） |
| `admin.html` | G1-5 | 管理画面（自分の投稿のみ編集・削除可、G7-2決定を反映） |

## 確定後の移植方針

見た目がこれでOKになったら、`class` → `className` に置き換えつつ、対応する `src/app/**/page.tsx` にレイアウトを移植する（G4-4, G5-2）。データはSupabaseから取得する形に置き換える。
