# Lately

自分専用の近況報告サイト。買ってよかったモノ（Things）と日々の日記を、なるべく手間なく記録・公開する。

- 初期の企画メモ: [`requirements.md`](./requirements.md)
- 実装内容も反映した正式な要件定義書: [`docs/要件定義書.md`](./docs/要件定義書.md)

## 技術スタック

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Supabase（Database / Storage）※Authは使わない予定

## セットアップ

```bash
npm install
npm run dev
```

http://localhost:3000 を開いてください。
